# Alvenn ERP

CRM Next.js com Firebase, captação via Resend/Z-API e agendamento nativo.

Consulte [IMPLEMENTACAO.md](IMPLEMENTACAO.md) para instalação, variáveis de ambiente, integração do formulário, estrutura Firestore, regras, índices e configuração do cron.

A rota legada `/api/v1/leads` agora exige a mesma autenticação de `/api/leads`.
